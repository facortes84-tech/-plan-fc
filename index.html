📡 Sensores — Edge 1030 (según tu lista)
Potencia → usa UNA sola fuente: Quarq AGC16590. Es la misma que usas en la calle y en el rodillo, así el FTP es comparable.
Quita o desactiva duplicados: “16590” (es el mismo Quarq por ANT+), “Rodillo” y “Wahoo KICKR C88” como fuente de potencia. El KICKR déjalo solo como control del rodillo (ERG) si lo usas así.
“48863” (icono de plato): abre el sensor y revisa. Si es cadencia/crank y el Quarq ya da cadencia, elimínalo.
FC: “Reloj FC” es el 945 emitiendo (óptico de muñeca, retrasa). Para easy run y deriva, lo ideal es banda pectoral (Garmin HRM 600 / Pro Plus o Polar H10), emparejada con Edge y 945.

Configurar (Edge):
1. Menú → Sensores → toca cada sensor → Detalles: el que marca vatios al pedalear es el bueno; “Quitar” los repetidos.
2. Sensor Quarq → Calibrar potencia (cuerpo quieto, pedales sin carga) antes de cada test.
3. KICKR: calibra (spindown) desde la app Wahoo antes del test FTP.
4. Perfil de actividad “Rodillo/Indoor”: GPS apagado; campos: Potencia 3 s, Potencia vuelta, Cadencia, FC, Tiempo vuelta, Zona de potencia.
5. Edge → Mi perfil → Zonas de potencia: verifica qué FTP usa (Garmin Connect 246 W). Tras el test, escribe el nuevo FTP aquí, en Garmin y en el Edge.
6. 945 (run): campos FC, FC vuelta, cadencia, ritmo vuelta; alerta FC alta = 146 lpm.
⌚ Cómo crear un entreno en Garmin (6 pasos)
1. Abre connect.garmin.com (Safari) o la app Garmin Connect → Entrenamiento → Entrenamientos → Crear un entrenamiento. En web es más cómodo.
2. Elige el deporte (Ciclismo / Correr / Natación en piscina) y pega el nombre exacto (botón 📋).
3. Añade los pasos en orden: tipo (Calentamiento, Correr/Pedalear, Recuperación, Descanso, Enfriamiento) → duración → objetivo.
4. Objetivo: Ciclismo = Potencia personalizada (mín–máx W). Correr = FC personalizada (mín–máx lpm). Natación = distancia.
5. Para series usa Repetir (N veces) con intervalo + recuperación dentro.
6. Guardar → Enviar al dispositivo (Edge 1030 para bici, Forerunner 945 para run/nat) → sincroniza. En el aparato: Entrenar/Entrenamientos → elegir.
Garmin no arma multisport estructurado: un brick son 2 entrenos (bici + run). La cadencia no es objetivo de paso: actívala como campo de datos o alerta. Si cambias FTP/LTHR, los vatios/FC de los entrenos ya creados no se actualizan solos: rehazlos.
